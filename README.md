# Pulse Clinic — Healthcare Website

## Industry
Healthcare (Clinic / Hospital)

## Objective
A responsive, clean-and-trustworthy website for a fictional multispecialty
clinic in Bhubaneswar, built for SuuSri AI's Week 2 Web Development Task.
Built with plain HTML, CSS, and JavaScript.

## Technologies Used
- HTML5, CSS3 (Flexbox & Grid, custom properties, responsive design)
- JavaScript (vanilla) -- all interactivity

## Sections
Hero, About, Departments/Services, Doctors, Health Packages, Why Choose Us,
Testimonials, OPD Schedule, FAQ, Appointment Booking, Contact, Footer.

## Interactive Features
1. Sticky navbar that changes on scroll
2. Mobile hamburger menu with slide-in panel
3. Animated counters in the hero stats (count up when scrolled into view)
4. FAQ accordion -- click a question to expand/collapse its answer
5. Appointment form validation with a success message
6. Back-to-top button

## Design Updates
- Professional healthcare color scheme (medical blue-teal palette)
- Hospital image added to showcase the facility
- Doctor photos in square format with modern card design
- Custom logo with medical symbol
- Clean, trust-building layout with card-based UI

## How to Run
Open `index.html` in VS Code -> right-click -> "Open with Live Server".
