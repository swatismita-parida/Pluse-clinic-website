# Pulse Clinic — Healthcare Website

## Industry
Healthcare (Clinic / Hospital)

## Objective
A responsive, clean-and-trustworthy website for a fictional multispecialty clinic in Bhubaneswar, built for SuuSri AI's Week 2 Web Development Task. Built with HTML, CSS, JavaScript, and GSAP.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid, custom properties, responsive design)
- JavaScript (vanilla)
- GSAP + ScrollTrigger (for animations)

## Sections
Hero, About, Departments/Services, Doctors, Health Packages, Why Choose Us, Testimonials, OPD Schedule, FAQ, Appointment Booking, Contact & Location (Google Map), Footer.

## Interactive Features
1. Sticky navbar that changes on scroll (Handled by GSAP)
2. Mobile hamburger menu with slide-in panel
3. Animated counters in the hero stats (count up when scrolled into view)
4. FAQ accordion -- click a question to expand/collapse its answer
5. Appointment form validation with a success message
6. Back-to-top button
7. Google Map embedded in the Contact section

## GSAP Animations Used
1. Hero entrance animations (fade + slide up for text and buttons)
2. ScrollTrigger-based reveal animations for all sections (fade + slide up)
3. Smooth sticky navbar background transition on scroll using GSAP ScrollTrigger

## How to Run
Open `index.html` in VS Code -> right-click -> "Open with Live Server".
